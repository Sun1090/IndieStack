# 国际化方案

## 架构概览

项目使用 `next-intl` 4 实现国际化，采用 **Cookie 策略**（`localePrefix: "never"`），语言偏好存储在 Cookie 中，URL 不包含语言前缀。

```mermaid
graph TD
    subgraph I18nSystem["next-intl 国际化系统"]
        Routing["routing.ts<br/>语言定义 + 路由策略"]
        Request["request.ts<br/>服务端请求配置"]
        Navigation["navigation.ts<br/>导航 API 封装"]
    end

    subgraph Messages["消息文件"]
        ZH["messages/zh-CN/<br/>17 个命名空间"]
        EN["messages/en/<br/>17 个命名空间"]
    end

    subgraph Runtime["运行时"]
        Cookie["Cookie: app-locale"]
        LoadMessages["loadMessages(locale)<br/>动态加载命名空间"]
        IntlProvider["NextIntlClientProvider<br/>注入 messages"]
    end

    Routing --> Request
    Request --> Cookie
    Cookie --> LoadMessages
    LoadMessages --> ZH
    LoadMessages --> EN
    LoadMessages --> IntlProvider
```

## 语言配置

| 配置项 | 值 |
|--------|-----|
| 支持语言 | `zh-CN`（简体中文）、`en`（English） |
| 默认语言 | `zh-CN` |
| 路由策略 | `localePrefix: "never"` |
| Cookie 名称 | `app-locale` |

## 消息加载流程

```mermaid
sequenceDiagram
    participant R as Root Layout
    participant RC as request.ts
    participant C as cookies()
    participant LM as loadMessages()
    participant FS as messages/*.json
    participant P as Providers

    R->>RC: getRequestConfig()
    RC->>C: 读取 app-locale Cookie
    C-->>RC: locale (或默认 zh-CN)
    RC->>LM: loadMessages(locale)
    loop 17 个命名空间
        LM->>FS: import(`messages/${locale}/${ns}.json`)
        FS-->>LM: namespace 消息对象
    end
    LM-->>RC: 合并后的 messages 对象
    RC-->>R: { locale, messages }
    R->>P: NextIntlClientProvider(locale, messages)
```

## 使用方式

### 服务端组件

```tsx
import { getTranslations } from "next-intl/server"

export default async function Page() {
  const t = await getTranslations("dashboard")
  return <h1>{t("title")}</h1>
}
```

### 客户端组件

```tsx
import { useTranslations } from "next-intl"

function Component() {
  const t = useTranslations("common")
  return <p>{t("welcome")}</p>
}
```

### 导航 API

```tsx
import { Link, useRouter, usePathname, redirect } from "@/i18n/navigation"

// 内部链接
<Link href="/dashboard">{t("nav.dashboard")}</Link>

// 编程式导航
const router = useRouter()
router.push("/dashboard")
```

## 安全函数

| 函数 | 功能 |
|------|------|
| `isValidLocale(locale)` | 判断字符串是否为支持的语言 |
| `getSafeLocale(locale)` | 获取安全语言值，无效则返回默认 |
