# v0.10.0（2026-09-13）

v0.10.0 把界面层从「逐页手写」收敛为可复用系统。标签、颜色阶、骨架屏、空态不再由每个页面各自实现，
而是各自只有一个落脚点——并且加了门禁：页面一旦退回旧写法，构建直接失败。

本版本**没有数据库迁移**，是纯应用层改动。

## 亮点

- **Tailwind v4 原生主题机制**：两段手写动画（不确定态进度条、路由切换进度条）从「裸 `@keyframes` +
  `@layer utilities`」迁到 `@theme` token（`--animate-progress-indeterminate` / `--animate-navprogress`），
  keyframes 内联进同一块，使用处回到普通 `animate-*` 工具类；删除无引用的 `.step` / `.step:before` 死代码；
  试点页与共享表单的 v3 类名升级（`bg-gradient-to-b` → `bg-linear-to-b`、`outline-none` → `outline-hidden`）。
- **design token 注册表**：新增 `src/lib/design/tokens.ts` 登记 39 个 token（含 `--success` / `--warning` /
  `--info` 三组语义色，各带 foreground）。11 个业务文件从 Tailwind 原生调色板（`bg-green-500`、
  `text-amber-600`、`bg-red-500`…）迁到语义工具类，深色模式首次获得统一回退。同时补上
  `--color-chart-1..5` 缺失的 `@theme` 映射——此前 `text-chart-N` / `fill-chart-N` 实际并不存在。
- **共享表单字段原语**：`src/components/shared/form-field.tsx` 用一层 context 统一接线 label、控件、描述与错误，
  自动注入 `htmlFor` / `id`、合并 `aria-describedby`、错误时写 `aria-invalid="true"`，描述与错误各有稳定 id；
  原生下拉下沉到 `native-select.tsx`，15+ 个表单完成迁移。
- **共享加载 / 空 / 错误状态**：`PageLoading`（`cards` / `dashboard` / `stats` / `list` / `spinner`）与
  `LoadingIndicator` 是加载态单一来源，`EmptyState` 负责空态，新增的 `ErrorState` 负责错误态。容器带
  `aria-busy="true"`，并通过 next-intl 输出 `role="status"` 的屏幕阅读器播报——此前 3 个路由骨架完全没有
  `aria-busy`，加载文案还是硬编码中文。10 处裸空态段落与 4 个错误边界完成迁移，两个零引用的重复加载组件
  （`page-loader.tsx`、`loading-state.tsx`）被删除。
- **深色模式首帧修复**：根布局注入带 CSP nonce 的阻塞脚本，在 CSS 解析前写好 `<html>` 的 class 与
  `color-scheme`，深色用户不再看到一帧浅色。同时修掉存储键不一致（Provider 写 `ui-theme`、其它地方读
  `theme`）导致刷新后主题丢失的问题，键名与解析规则收口到 `src/lib/theme/theme.ts`。
- **移动端断点回归**：新增 375 / 768 / 1280 三个断点的 `e2e/responsive.spec.ts`，暴露两个真实缺陷——
  容器固定 2rem 内边距把内容挤出 375px 视口（`scrollWidth` 428 > 375），以及仪表盘侧边栏
  `hidden md:block` 让手机端导航完全不可达。现在手机 1rem、≥640px 2rem，并新增
  `MobileDashboardNav`（ui/sheet 抽屉，跳转自动关闭）恢复可达性。
- **键盘与屏幕阅读器修复**：基于角色与可访问名称的 `e2e/keyboard.spec.ts` 暴露四处缺口——跳过导航的目标
  不可聚焦、移动端菜单忽略 `Esc` 且丢失焦点、折叠侧边栏按钮没有可访问名称与状态、`?` 快捷键在
  contenteditable / `role="textbox"` 与带修饰键组合下误触发。
- **四道 UI 门禁**：`pnpm check:tailwind`、`check:tokens`、`check:fields`、`check:states` 把上述约定变成
  可执行规则（7 / 8 / 3 / 4 类规则码），全部接入 `pnpm check:all` 与 CI。

## 升级说明

1. 无迁移、无环境变量变更，部署顺序不受约束。
2. 删除的 `page-loader.tsx` / `loading-state.tsx` 在删除前就是零引用；若下游分支仍在 import，
   构建会立即失败，而不是静默回退。
3. `globals.css` 现在是状态色与动画 token 的唯一出处。要改颜色请改 `:root` / `.dark` 变量，
   不要改调用处的工具类——`pnpm check:tokens` 会强制这一点。
4. 推送前请运行 `pnpm check:all`：四道新门禁都在其中。

## 已知限制

状态与表单字段门禁是**静态写法审计**，不是语义分析：它们能拦住原生 `<select>`、复制的控件类名长串、
白名单外的 `animate-spin`、以及「`text-center` + 固定纵向内边距」的裸占位符，但不能证明运行时 ARIA
行为正确——那由原语单测覆盖。视觉回归目前仍只覆盖 4 个公共页（首页 / 功能页 / 定价页 / 登录页），
分辨率固定 1440×900。
